## 1. โครงสร้างไฟล์

```
(root ของ repo)
├─ index.html          ← หน้าเว็บทั้งหมด (HTML + CSS + JS อยู่ในไฟล์เดียว)
├─ data.json           ← รายชื่อ 318 คน
├─ README.md           ← ไฟล์นี้ (ไม่ขึ้นเว็บ ไม่ต้องอัปก็ได้)
└─ certs/
   ├─ B6602291.jpg
   ├─ B6603625.jpg
   └─ ... รวม 318 ไฟล์
```

**กฎเดียวที่ห้ามพลาด:** ชื่อไฟล์รูปต้องเป็น `<รหัสนักศึกษา>.jpg`
ถ้าชื่อไม่ตรงกับ `i` ใน `data.json` คนนั้นจะกดแล้วรูปไม่ขึ้น

## 2. รูปแบบ data.json

เป็น array ของ object ตัวย่อ 4 ตัว:

```json
[{"i":"B6602291","n":"NUCHJARIN RUNGRUANG","c":"1001","g":1}, ...]
```

| คีย์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `i` | รหัสนักศึกษา (ใช้ตั้งชื่อไฟล์รูปด้วย) | `B6602291` |
| `n` | ชื่อ-สกุลภาษาอังกฤษ ตามที่พิมพ์บนเกียรติบัตร | `NUCHJARIN RUNGRUANG` |
| `c` | เลขท้าย CERT-ID (เว็บจะเติม `DGT-YTLDP2026-` ให้เอง) | `1001` |
| `g` | รุ่น — `1` หรือ `2` | `1` |
| `p` | *(ใส่หรือไม่ใส่ก็ได้)* ใส่ `1` ถ้าอยู่ในรายชื่อแต่ยังไม่มีไฟล์รูป | `1` |

## 3. อัปขึ้น GitHub Pages (0–100)

### 3.1 สร้าง repo

1. ไปที่ <https://github.com/new>
2. **Repository name** — เช่น `YTLDP2026` (ตั้งชื่ออะไรก็ได้ แต่จะไปอยู่ใน URL)
3. เลือก **Public** (ถ้าเป็น Private จะเปิด GitHub Pages ฟรีไม่ได้)
4. **ไม่ต้อง** ติ๊ก *Add a README file*
5. กด **Create repository**

### 3.2 อัป 3 ไฟล์หลักก่อน

1. ในหน้า repo ที่ว่างอยู่ กดลิงก์ **uploading an existing file**
   (ถ้าไม่เจอ ให้ไปที่ **Add file ▾ → Upload files**)
2. ลาก `index.html` กับ `data.json` ลงไป
3. ด้านล่างกด **Commit changes**

### 3.3 อัปโฟลเดอร์ certs ทีละชุด

GitHub เว็บอัปได้ **ไม่เกิน 100 ไฟล์ต่อครั้ง** ผมเลยแบ่งมาให้แล้ว 4 ชุด
(`certs_1_of_4.zip` … `certs_4_of_4.zip` — ชุดละ 80/80/80/78 ไฟล์)

ทำซ้ำชุดละรอบ:

1. แตก zip ออกมา จะได้โฟลเดอร์ชื่อ **`certs`** (ชื่อนี้สำคัญ ห้ามเปลี่ยน)
2. ในหน้า repo กด **Add file ▾ → Upload files**
3. **ลากทั้งโฟลเดอร์ `certs`** ลงไปในกรอบ
   *ลากโฟลเดอร์ไม่ได้?* — เปิดเข้าไปในโฟลเดอร์ `certs` แล้ว `Ctrl/Cmd + A`
   เลือกรูปทั้งหมด ลากเฉพาะไฟล์รูปลงไป **แล้วพิมพ์ `certs/` นำหน้าในช่องชื่อไฟล์**
   (วิธีที่ชัวร์กว่าคือใช้ Chrome/Edge แล้วลากทั้งโฟลเดอร์)
4. กด **Commit changes** แล้วรอจนอัปเสร็จ
5. ทำซ้ำกับชุดที่ 2, 3, 4 — ชุดหลัง ๆ จะไปรวมในโฟลเดอร์ `certs` เดิมเอง

> เช็กก่อนไปต่อ: เปิดโฟลเดอร์ `certs` ใน GitHub ต้องขึ้นว่า **318 files**

### 3.4 เปิด GitHub Pages

1. ในหน้า repo กดแท็บ **Settings** (ไอคอนเฟือง บนขวา)
2. เมนูซ้ายมือ เลื่อนหา **Pages**
3. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอประมาณ 1–3 นาที แล้วรีเฟรชหน้านี้ จะขึ้นกล่องเขียวพร้อมลิงก์

URL จะเป็น:

```
https://<ชื่อบัญชี>.github.io/<ชื่อ-repo>/
```

### 3.5 เช็กก่อนประกาศ

เปิดลิงก์แล้วลองพิมพ์:

| ลองพิมพ์ | ต้องได้ |
|---|---|
| `B6602291` | NUCHJARIN RUNGRUANG · รุ่นที่ 1 · `DGT-YTLDP2026-1001` |
| `B6843960` | PHUNKAWEE RAWKLANG · รุ่นที่ 2 · `DGT-YTLDP2026-2148` |
| `B6000000` | ขึ้นกล่องส้ม “ไม่พบรหัส” |

แล้วกดปุ่ม **บันทึกเกียรติบัตร** ดูว่าโหลดไฟล์ได้จริง
ลองบนมือถือด้วยสักรอบ (จอแคบ ปุ่มจะเรียงลงมาเป็นแถวเดียว)

## 4. เวลาต้องแก้ทีหลัง

| อยากแก้อะไร | ทำยังไง |
|---|---|
| เปลี่ยนรูปเกียรติบัตรทั้งชุด (เช่น แก้วันที่ใน Canva ใหม่) | อัปไฟล์ชื่อเดิมทับลงใน `certs/` ได้เลย ไม่ต้องแตะ `index.html` |
| เพิ่มคนใหม่ | เพิ่ม object ใน `data.json` + อัปรูป `<รหัส>.jpg` ลง `certs/` |
| คนอยู่ในรายชื่อแต่ยังไม่มีรูป | ใส่ `"p":1` ใน object ของคนนั้น เว็บจะขึ้นกล่อง “ไฟล์ยังอยู่ระหว่างจัดทำ” แทนที่จะบอกว่าไม่พบ |
| แก้ข้อความ/สีบนหน้าเว็บ | แก้ใน `index.html` ไฟล์เดียวจบ (CSS อยู่ใน `<style>` บนสุด) |
| แก้วันที่ของรุ่นที่โชว์บนหน้าเว็บ | ค้นคำว่า `ส.ค. 2026` ใน `index.html` — มี 2 จุด คือชิปด้านบน (`<ul class="gens">`) กับใน JS ตรง `document.getElementById("rgen")` |

> หลังอัปทับ ถ้าหน้าเว็บยังขึ้นของเก่า ให้กด hard refresh (`Ctrl/Cmd + Shift + R`)
> GitHub Pages จะ deploy ใหม่เองทุกครั้งที่ commit ใช้เวลาราว 1–2 นาที

## 5. หมายเหตุทางเทคนิค

- ทั้งเว็บเป็น static ล้วน ไม่มี backend ไม่มี database ไม่เก็บข้อมูลผู้ใช้
- `data.json` โหลดด้วย `fetch()` ครั้งเดียวตอนเปิดหน้า (ขนาด ~18 KB)
- การค้นหายืดหยุ่น: พิมพ์ตัวเล็ก/ตัวใหญ่, มีเว้นวรรค, มีขีด `-` `_` `.` ได้หมด
  และพิมพ์เลขล้วน (เช่น `602291`) ระบบจะลองเติม `B` / `B6` ให้เอง
- โหลดรูปจะไล่ลองนามสกุล `.jpg → .png → .jpeg → .JPG → .PNG` อัตโนมัติ
  เผื่อวันไหน export ออกมาคละนามสกุล
- ฟอนต์ใช้ Google Fonts (Mali, Sarabun, IBM Plex Mono) — โหลดจาก CDN
  ถ้าเน็ตเข้าไม่ถึง Google จะ fallback เป็นฟอนต์ระบบ หน้ายังใช้งานได้ปกติ
- ธีมวาดด้วย CSS/SVG ทั้งหมด ไม่ได้เอารูปภาพมาทำพื้นหลัง
